# Завод котов — чеклист для друзей (Windows)

## Что уже в билде (вертикальный срез)

1. Main Menu → офлайн или лобби (до **12** игроков).
2. Зал с зонами: КБ, склад, цех (резка/токарный/фрезер/пресс), сборка, шеф.
3. Пайплайн детали: задания → замер → Paint-чертёж → заказ заготовки → станок → сборка.
4. Смена: таймер, квота, бюджет, брак, случайные события, задания шефа.
5. Чат (T), пауза (Esc), настройки (ник / громкость / мышь).

## Управление

| Клавиша | Действие |
|---------|----------|
| WASD | Ходьба |
| Мышь | Обзор |
| E | Взаимодействие |
| G | Положить предмет |
| T | Чат |
| Esc | Пауза / закрыть панель станка |
| A/D + Пробел | Мини-игра станка (сдвиг / резать) |

## Как пройти срез вдвоём

1. Хост: **Создать лобби** → друг: **Подключиться**.
2. У **стола заданий** выбрать деталь (начните с «Основание» — резка).
3. **Стол замера** → записать размеры.
4. **Стол чертежа** → нарисовать от руки, выбрать металл, «Отправить в цех».
5. **Склад** → заказать заготовку → взять куб `[E]`.
6. **Резка** → совместить A/D, Пробел / кнопка «Резать».
7. Повторить для вала (токарный) и крышки (пресс).
8. **Сборка** → «Сдать изделие».

## Билд

1. Unity: File → Build Settings → сцены `MainMenu`, `MainScene`.
2. Platform: Windows.
3. Для онлайн: проект должен быть связан с Unity Gaming Services (как при разработке).
4. Хост-миграция **не поддерживается** — хост не должен выходить во время смены.

## Известные упрощения прототипа

- Предметы пока локальные (не полноценный NetworkObject-sync на всех клиентах).
- Станции занимаются мягко (без жёсткого сетевого лока).
- Модели станков — цветные примитивы.
