# Завод котов — игровой дизайн (ГДД)

Кооперативная комедийная игра про завод: коты в касках вместе собирают изделия. Хаос, кривые чертежи, станки и общий успех смены.

---

## 1. Высокоуровнево

| Параметр | Решение |
|----------|---------|
| Жанр | Кооп, заводской крафт / «ошибки обязательны» |
| Режим | Один кооп с **ролями**, не PvP команд |
| Игроки | **2–12** |
| Тон | Комедия / хаос |
| Атмосфера | Лёгкий налёт совка, без перегиба |
| Графика | В духе REPO |
| Сеть | Игрок-хост |
| Локация | Одна, богатая деталями |

**Фантазия игрока:** измерил криво → начертил от руки → заказал не тот металл → на станке срезал «по линейке» → деталь не влезла → ор в голосовой → всё равно сдали квоту.

---

## 2. Роли (одна команда завода)

Роли — специализации внутри одного кооператива. Можно договориться, кто чем занимается; жёсткого «ты навсегда чертёжник» можно не делать, но пайплайн один.

### 2.1. Чертёжники / сборщики / снабжение

1. Получают задание на изделие (или выбор из нескольких по сложности).
2. Видят полупрозрачный эталон → инфо: число деталей, допуски (± мм), марки металлов.
3. «Разбирают» на полупрозрачные детали.
4. По детали: **замер** → **чертёж** → допуск + марка металла → отправка на цех.
5. Когда деталь готова — **сборка** в изделие (подошла / не подошла → переделка).
6. **Склад изначально пуст** — заказывают заготовки с бюджета. Лишние заказы из-за косяков бьют по очкам/бюджету.

Замер (в идеале): длина, ширина, высота, диаметры отверстий, углы. Один меряет, другой чертит — нормальный кооп внутри роли.

### 2.2. Цех / станочники

1. Получают чертёж.
2. Идут на склад за заготовкой.
3. Обрабатывают на станках.
4. Отправляют готовую деталь сборщикам.

**Станки:**

| Станок | Назначение |
|--------|------------|
| Токарный | Круглые болванки, форма |
| Фрезерный | Отверстия, выемки |
| Пресс / обрезка | Длина, гибка листов/плит |

Плюс набор свёрл разного диаметра (влияние на допуски).

Организация свободная: один станок = один кот, или один кот ведёт деталь целиком.

---

## 3. Черчение: Paint с прокачкой

База — **рисование от руки**, как в Paint: кривые линии — фича, не баг.

**Прокачка** открывает удобства, не убивая хаос:
- прямые линии, окружности, прямоугольники;
- сетка / привязка;
- копирование размеров с замера в чертёж;
- слои / шаблоны для типовых деталей;
- более точные инструменты на поздних «сменах».

Новички страдают кракозябрами → ветераны рисуют чище, но косяки замера и станков всё равно ломают план.

---

## 4. Станки: «среднее» между мини-игрой и симом

Не чистый симулятор параметров и не только «провода».

**Ориентир геймплея:** действия руками с допуском — например, **вырезать деталь по линейке** (совместить разметку, держать линию, не уехать за допуск).

Направление для остальных станков в том же духе:
- токарный — крутить/останавливать на метке, снять «лишнее» до размера;
- фрезер — попасть сверлом/фрезой в точку и глубину;
- пресс — совместить линию реза/гиба с разметкой.

Ошибка = деталь вне допуска = брак или «почти, но сборка орёт».

---

## 5. Цикл игры: «среднее» между сессией и кампанией

**Одна партия = рабочий день (смена).**  
Внутри смены — поток изделий / квота, не одно задание и конец.

**Между сменами (лёгкая мета):**
- небольшая прокачка Paint / станков / свёрл;
- разблокировка чуть более сложных изделий;
- накопление к «финальному» заказу.

**Финал арки (пока намёк):** «гига-робот» / особое изделие — несколько смен подготовки + одна жирная финальная сборка. Не обязательно длинная кампания AAA — скорее **короткий сезон из нескольких смен**.

Скоринг смены (черновик):
- квота изделий;
- перевыполнение = награда;
- бюджет / лишние закупки = штраф;
- брак и переделки жрут время.

## 6. Случайные события

Идея зафиксирована, список ещё пустой. Нужны события, которые:
- ломают план обеих ролей;
- усиливают комедию;
- не полностью AFK-шатют половину лобби.

Примеры на обсуждение: отключение станка, пересорт металла на складе, «проверка от шефа», кривой эталон от заказчика, кот утащил свёрла, внеплановый срочный заказ.

---

## 7. Проблема простоя (открыто)

Чертёжники ждут цех → цех ждёт чертежи/металл. В 2–12 игроков это будет заметно.

Пока **решения нет**. Кандидаты из брейншторма:
- индивидуальные задания от шефа;
- побочные задачи поверх основной работы;
- давление временем / непрерывный поток квоты;
- подготовительные мини-активности (наладка, провода) в начале смены и в окнах ожидания.

**Нужно решить отдельно**, когда станет яснее ритм прототипа.

---

## 8. Пайплайн одной детали (сводка)

```
Эталон изделия
    → разбор на детали
    → замер
    → чертёж (Paint + прокачка)
    → заказ металла (бюджет)
    → склад → станки («по линейке» и аналоги)
    → деталь к сборке
    → вставка в изделие (ок / брак → переделка)
```

Узкие места для веселья и ор: замер, чертёж, марка металла, допуск на станке, сборка.

## 10. Следующие шаги дизайна (когда будете готовы)

1. Набросать **1 изделие из 3–4 деталей** и пройти пайплайн на бумаге.
2. Описать **одну** станковую мини-схему («резка по линейке») до кликабельного прототипа.
3. Решить простой для 2 игроков vs 8–12 (решения могут отличаться).
4. Список из 5–8 случайных событий под комедию.
5. Набросать 3 «дня» арки с финальным гига-заказом.
